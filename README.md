# Sentiment Analysis Using Text Mining

A simple college-level web application that classifies user-entered text as **Positive 😊, Negative 😞, or Neutral 😐**.

## 1. Objective

The project demonstrates the complete flow of:

**Text Input → Text Cleaning → Tokenization/Stop-word Removal → TF-IDF → Logistic Regression → Probability → Web Result + Chart**

It uses Flask for the backend and HTML/CSS/JavaScript for the frontend.

## 2. Features

- Three-class sentiment classification: positive, negative, neutral
- Text cleaning and preprocessing with NLTK
- TF-IDF feature extraction
- Logistic Regression classifier
- 80/20 stratified train/test split
- Accuracy, precision, recall and F1-score
- Saved model and vectorizer using Joblib
- Flask JSON API
- Responsive UI
- Confidence percentage
- Dynamic Chart.js probability chart
- Empty/invalid input validation

## 9. Text Mining Pipeline

### Step 1: Text Input
The user enters a review or sentence in the browser.

### Step 2: Cleaning
The application:
- converts text to lowercase
- removes URLs
- removes punctuation/special characters
- splits text into tokens
- removes English stop words

### Step 3: TF-IDF
TF-IDF converts text into numerical features that the machine-learning model can understand.

### Step 4: Logistic Regression
The classifier uses the TF-IDF features to predict one of the three classes.

### Step 5: Probability
`predict_proba()` produces a probability for every class.

### Step 6: Visualization
JavaScript sends the probabilities to Chart.js and creates a bar chart.

## 10. What is TF-IDF?

TF-IDF means **Term Frequency–Inverse Document Frequency**.

It gives higher importance to words that are useful for distinguishing documents and lower importance to words that occur in many documents.

A simplified formula is:

```text
TF-IDF = TF × IDF
```

Where:
- TF = term frequency in a document
- IDF = inverse document frequency across documents

## 11. What is Logistic Regression?

Logistic Regression is a supervised machine-learning classification algorithm.

Although its name contains "regression", it is commonly used for classification. Here it learns relationships between TF-IDF features and the three sentiment classes.

It is suitable for this college project because it is:
- fast
- simple
- explainable
- effective for text classification

## 12. Three-Class Classification

The model is trained with:

```text
positive
negative
neutral
```

It is not a binary positive/negative model.

For every input, the application obtains three class probabilities and displays the class with the highest predicted probability.

## 13. Model Evaluation

`train_model.py` calculates:

- Accuracy
- Weighted Precision
- Weighted Recall
- Weighted F1-score
- Confusion Matrix

The metrics shown by the application are calculated from the included sample dataset and the fixed 80/20 test split. If you replace the dataset, retrain the model and use the newly printed metrics.

## 14. Dataset

## 15. API

